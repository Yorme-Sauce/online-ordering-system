# Nadine's Catering - Online Food Ordering System 🍽️

A modern, responsive web-based online food ordering system for Nadine's Catering service. Built with vanilla HTML, CSS, and JavaScript.

## Features

✨ **Core Features:**
- 🍽️ Dynamic menu with multiple categories (Appetizers, Main Courses, Desserts, Beverages)
- 🛒 Shopping cart with add/remove functionality
- 📊 Real-time cart quantity updates
- 💳 Checkout form with customer information collection
- 💾 Local storage for cart persistence
- 📱 Fully responsive design (mobile, tablet, desktop)
- 🎨 Modern and clean UI with smooth animations


## Getting Started

### Prerequisites
- No backend server or dependencies required
